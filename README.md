# My Music Site

## Setup

Install dependencies:

npm install

Run:

npm start

Open:

http://localhost:3000

## Add your playlist

Edit:

public/js/player.js

Replace the example entries in `playlist` with your YouTube video IDs.

Example:

const playlist = [
  {
    title: "After Dark",
    artist: "Mr.Kitty",
    videoId: "YOUR_VIDEO_ID"
  }
];

## Background

Put your image here:

public/assets/background.jpg

The directory is already configured for it.
